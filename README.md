# ollama-ru-bench

Одна команда, чтобы быстро понять, как модель из Ollama работает для русскоязычных задач: пишет ли по-русски без ошибок и выдумок, решает ли простую задачу на код, считает ли и держит ли формат ответа. Работает и с локальной Ollama, и с Ollama Cloud.

```
Model               | tok/s | TTFT  | RU   | Code | Math | Format
--------------------+-------+-------+------+------+------+-------
beam                | 565.5 | 0.52s | 7/10 | 3/3  | ✓    | ✓
deepseek-v4.1-flash | 289.0 | 0.43s | 7/10 | 3/3  | ✓    | ✓
```
*Наш прогон через Ollama Cloud, 16.10.2026. Судья — `deepseek-v4.1-flash`.*

## Что проверяется

| Тест | Как |
|---|---|
| `ru_rewrite` | Пересказ английской новости по-русски: заголовок и 3 предложения, только факты. С `--judge MODEL` другая модель ставит оценку 1–10 и перечисляет ошибки. |
| `code` | Функция `top_words(text, n)`. Код модели запускается на настоящих юнит-тестах в отдельном процессе: белый список импортов, без `open/exec/eval`, лимиты CPU и памяти, таймаут. |
| `math` | Сумма цифр 2026² (ответ 28). |
| `format` | Ровно 3 строки с «- », не больше 8 слов, без эмодзи. |
| Скорость | Время до первого токена (TTFT) и токены в секунду по потоковому ответу. |

Режим размышлений (`think`) выключен, чтобы модели сравнивались одинаково.

## Установка и запуск

Нужен Python 3.10+, сторонних зависимостей нет.

```bash
git clone https://github.com/neurostack-lab/ollama-ru-bench && cd ollama-ru-bench
pip install -e .

# локальная Ollama
ollama-ru-bench qwen3.8:14b gemma4:31b

# Ollama Cloud
export OLLAMA_API_KEY=...
ollama-ru-bench beam deepseek-v4.1-flash --host https://ollama.com --judge deepseek-v4.1-flash --json report.json
```

## Как сделан этот проект

Код написала модель **Beam** от Reflection (501B параметров, из них 23B активных) через Ollama Cloud. Ушёл один запрос по нашему техзаданию, генерация заняла 7,4 секунды. Мы прогнали тесты и поправили один баг: таймер TTFT запускался после ответа сервера, поэтому задержка занижалась. Остальное осталось как Beam написала.

## Ограничения

- Один быстрый прогон — это замер, а не бенчмарк. Для выводов запускайте `--runs N` и смотрите разброс.
- Оценка русского зависит от модели-судьи.
- Песочница для кода защищает от случайностей, а не от целенаправленной атаки. Не запускайте модели, которым не доверяете, на важной машине.
